# CPU and DDR passive increment

Stack: #66 → #67 → this increment. Native lint **320 → 210**; the four changed
sheets go from **110 → 0** findings (104 orientations, six capacitor banks).

The shared TSX helper rotates two-pin rail parts toward power/ground and groups
capacitors by return and supply. Banks use 1.5-unit horizontal pitch with a
1-unit alternating offset so long reference labels have room. Adjacent body
gaps stay below the lint rule's 1-unit maximum. Resistors keep their original
schematic positions, and their connections are regenerated by the native build.

Validation: `tsci check schematic-placement index.tsx`, `tsci build index.tsx`,
and the evidence comparison against main `6647689` all pass.
All PCB arrays are exact, including all 940 vias, 747 traces, 1,505 SMT pads,
26 plated holes, 1,152 PCB components and 362 pours. All source nets, source
traces, internal connections, port IDs, pin numbers, and connectivity keys match.

The full source-port comparison exposed a stock-symbol inconsistency: rotation
reorders polarity synonyms, and nine imported-footprint capacitors lose redundant
`pos`/`neg` hints. This does not change numbered pins or connectivity. The checker
normalizes only these four polarity synonyms and alias order; no PCB field or
source connection is excluded. Supplier fetch warnings and the TSX metadata hash
remain excluded as documented in the box increment. The native
[TSX reproduction](reproductions/rotated-capacitor-aliases.tsx) and
[complete alias deltas](cpu-ddr/symbol-alias-changes.json) record the limitation;
tscircuit itself is unchanged.
