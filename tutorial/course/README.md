# Signal Integrity Course: example files

These are the runnable examples for the tscircuit docs course
[Signal Integrity Course](https://docs.tscircuit.com/guides/spice-simulation/si-course).
Each file is one lesson. Run any of them from the repo root:

```sh
bunx tsci simulate tutorial/course/03-rc-step.circuit.tsx                         # ngspice: prints a table
bunx tsci simulate tutorial/course/10-microstrip.circuit.tsx --output out/10      # pcb_spice: writes out/10/results.html
```

`pcb_spice` lessons need `fasthenry`, `FasterCap` and `ngspice` on `PATH`.
To run several files two at a time, use `tutorial/run-course.sh <files…>`.
Results go to `tutorial/course/out/`, which git ignores.

## Shared parts

- `teaching-buffer.tsx`: a 4-pad `Buffer` chip, its `teachingIbis()` binding,
  and the extraction settings.
- `teaching-board.tsx`: `LineBoard`, a 4-layer board with one line (or two,
  for crosstalk) between two buffers.
- `models/lvcmos33-teaching.ibs`: a **synthetic** 3.3 V LVCMOS IBIS model
  with 4, 12 and 24 mA drivers, generated by
  `models/generate-lvcmos33-teaching.py`. It is not a real part, so don't use
  it for design decisions.

## Settings that make `pcb_spice` converge here

- Route pad centre to pad centre with `pcbPath`. Otherwise the pipeline stops
  with `endpoint_position`.
- `straightened-stages` turns the whole route into one straight stage. With
  0.5 mm panels, FasterCap stopped converging for lines of 50 mm or more, so
  `maxPanelLength` is `2mm`.
- Use a thin dielectric and a narrow trace (0.16 mm over 0.0994 mm). A 2.9 mm
  trace on a 2-layer board timed out in FastHenry.
