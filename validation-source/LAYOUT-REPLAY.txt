Native source with saved routing

index.tsx remains the logical and schematic design. It contains real native
components and named nets. Its direct native PCB render has no saved traces:
routingDisabled prevents automatic rerouting and does not replay saved copper.
Manual native pcbPath traces still work under routingDisabled, but index.tsx
does not yet declare those saved paths or a faithful native physical replay.

The explicit replay workflow is:
  bun run replay:layout

This renders index.tsx fresh, checks that none of its static source dependencies
changed during rendering, then compiles the native logic/schematic with the
approved saved physical state. The generated display/export artifact is:
  validation-source/index-with-layout.circuit.json

Open that generated artifact for PCB paths and the complete fresh schematic;
keep index.tsx open for authoring. It is a compiled view, not a JSON logical
board imported by index.tsx. Seven freshly generated native array models are
retained separately in index-with-layout.models.json.

compile-layout.py validates component identities, physical pin names/ordinals,
named-net bindings, values/MPNs and declared internal metal connections. It
rebases native source/schematic IDs onto the saved physical identities and
copies every PCB/CAD record verbatim, including placement, routes, full-layer
via barrels, pours and mechanical geometry. Legacy physical debug-branch aliases
are retained only when they name connections already declared by native TSX;
their endpoint labels are regenerated from actual component/pin identities.

layout-binding-v5.json ties this replay to the approved saved physical hash and
a fingerprint of the native authoring placement/footprints at binding time.
The saved layout is the physical authority: it can differ from the original
native placement hints, and those differences are listed in the receipt.
Later native placement/footprint or logical changes reject replay instead of
silently moving parts, stretching traces, or dropping paths. Schematic-only
changes can be rendered and replayed normally. A genuinely changed board must
be routed/reviewed and bound explicitly as a new physical state.

index-with-layout-receipt.json records all input/output hashes, source dependency
hashes, the ID bijection and exact-physical preservation. Native schematic
router virtual-edge IDs remain as generated; no synthetic logical connections
are fabricated to fill those display-only placeholders.

layout-replay-fixture.circuit.tsx is a real native JSX fixture. Its tests verify
preserved top-to-bottom eight-layer vias, rejected net/value/placement/footprint
changes and retained saved paths after schematic-only edits.

Replay preserves the selected routing work in progress. It does not establish
new physical connectivity, clearance or DDR/HDMI signal-integrity margins.
